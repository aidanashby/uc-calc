# UC update reports

The scheduled monitoring routine saves a dated report here (`YYYY-MM-DD.md`) whenever the plugin's rates, costs, copy or spec need updating. Each report lists the settings to change, the files and lines, the new values, their effective dates and sources, and the tests and QA scenarios affected.

No report is written when nothing needs changing. See [`.claude/routines/uc-monitor.md`](../../.claude/routines/uc-monitor.md) for how the routine works.
